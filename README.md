# Market Microstructure Project

This repository contains my work on a market microstructure modelling project, with a focus on order imbalance, regime-based models, and Markov-chain approaches.

## Repository structure

- `project testing.ipynb` — Main project notebook containing the model development, analysis, and written report.
- `Cartea_notes.pdf` — Notes from Cartea et al., with emphasis on market making, order imbalance, market order arrivals, and regime-based modelling.
- `Hasbrouck_notes.pdf` — Notes from Hasbrouck, covering the Roll model, short-run price behaviour, and univariate time-series ideas relevant to the project.
- `LOG.md` - Dated log of the project, especially aspects that forced me to step back and think. A lot of the work done behind the scenes don't show up anywhere else but here.  

## Project direction

The project develops from a simple baseline model toward a richer regime-based model of market behaviour. The main motivation is to use observable market information, particularly order imbalance, to infer the probability of the market being in different regimes.

The literature notes are included to document the theoretical and empirical motivation behind the modelling choices used in the project.
